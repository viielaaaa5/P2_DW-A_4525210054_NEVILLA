## Deskripsi Website

Profil IMATIKA merupakan halaman web sederhana yang dibuat menggunakan HTML untuk menampilkan informasi mengenai Ikatan Mahasiswa Teknik Informatika. Website ini menggunakan konsep satu halaman dengan navigasi untuk memudahkan pengguna mengakses setiap bagian informasi.

## Isi Halaman

- **Header**: menampilkan nama IMATIKA serta slogan "Mencetak generasi terampil, kreatif, dan berdaya saing".
- **Navigasi**: menyediakan tautan menuju bagian Identitas, Program Keahlian, Alur Pendaftaran, dan Kontak.
- **Identitas Organisasi**: berisi logo IMATIKA serta informasi nama organisasi, alamat, dan akreditasi.
- **Program Keahlian**: menampilkan empat program keahlian, yaitu Artificial Intelligence, Network Cyber and Security, Data Science, dan Software Engineering.
- **Alur Pendaftaran**: menjelaskan enam tahapan untuk menjadi anggota IMATIKA, mulai dari pengisian formulir sampai pelantikan anggota.
- **Kontak dan Media Sosial**: berisi tautan Instagram dan alamat email IMATIKA.
- **Footer**: menampilkan informasi hak cipta dan email yang dapat dihubungi.

## Tag HTML yang Digunakan

| Tag HTML | Kegunaan |
|---|---|
| `<!DOCTYPE html>` | Menentukan dokumen menggunakan HTML5 |
| `<html lang="id">` | Menentukan elemen utama dan bahasa halaman |
| `<head>` | Menyimpan informasi dasar halaman |
| `<meta>` | Mengatur karakter yang digunakan pada dokumen |
| `<title>` | Menentukan judul halaman pada tab browser |
| `<h1>` dan `<h2>` | Membuat judul dan subjudul |
| `<p>` | Menampilkan teks dalam bentuk paragraf |
| `<nav>` | Membuat bagian navigasi halaman |
| `<a>` | Membuat tautan |
| `<img>` | Menampilkan logo IMATIKA |
| `<ul>` dan `<li>` | Membuat daftar informasi |
| `<ol>` | Membuat daftar yang memiliki urutan |
| `<b>` | Membuat teks menjadi tebal |
| `<hr>` | Membuat garis pemisah |
| `<small>` | Membuat teks berukuran kecil |

## Cara Menjalankan

1. Simpan kode HTML dengan nama file `Tugasprak.html`.
2. Pastikan file sudah tersimpan dengan ekstensi `.html`.
3. Buka file tersebut menggunakan browser seperti Google Chrome, Microsoft Edge, atau Mozilla Firefox.
4. Halaman Profil IMATIKA akan ditampilkan di browser.
